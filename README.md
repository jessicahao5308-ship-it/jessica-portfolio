# Jessica's Portfolio · 悉尼陪读妈妈

个人作品集网站 —— AI 时代的悉尼陪读妈妈。

> Sale myself · 用 Claude Code + Obsidian，把澳洲教育和新移民资源，系统化、产品化，分享给中文世界。

## Stack

- 纯静态 HTML + Tailwind CSS (CDN)
- 部署：GitHub Pages
- 无构建依赖、无 JS 框架

## 本地预览

直接双击 `index.html` 即可。

## 作品 / Works

`works/` 文件夹下，每一个作品是一个独立 HTML 文件。新增作品流程：

1. 把新作品 HTML 放进 `works/xxx.html`
2. 在 `index.html` 的「精选作品」section 加一张卡片
3. `git push` 自动重新部署

## 隐私原则

- 网站只放主动策展的对外作品
- **不自动同步** Obsidian 私人笔记
- 孩子真实姓名 / 学校信息 / 学习记录等敏感内容，永远不上线
